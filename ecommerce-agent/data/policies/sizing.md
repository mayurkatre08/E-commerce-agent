# Sizing Guide

## General Sizing Philosophy
Our clothing is designed with a **true-to-size** fit. If you are between sizes, we recommend sizing up for a relaxed fit or sizing down for a more fitted look.

## Size Change Policy
- Size changes on an order are allowed **only if the order has not yet shipped**.
- To request a size change, contact support with your order ID and the new size.
- If the desired size is out of stock, we will notify you and offer alternatives.

# Exchange Policy

## Overview
We offer **free exchanges** for a different size or color of the same item within **30 days** of delivery.

## Eligibility
- Item must be unworn, unwashed, and in original condition with tags attached.
- Exchanges are only available for the same product (different size or color).
- For a different product, please return the original item and place a new order.

## How to Request an Exchange
1. Log in and go to **Order History**.
2. Select the order and click **Request Exchange**.
3. Choose the item, select the new size or color.
4. Print the prepaid exchange shipping label.
5. Ship the item back within **7 days** of submitting the request.

## Exchange Shipping
- Domestic exchanges ship for **free** (both return and re-shipment).
- International exchanges: return shipping is the customer's responsibility; re-shipment is free.

## Exchange Timeline
- Once we receive your returned item, the exchange order is created within **1–2 business days**.
- You will receive a new tracking number via email.
- If the requested size/color is out of stock, we will contact you to offer alternatives or a full refund.

## Limitations
- Each item can only be exchanged **once**.
- Sale items can be exchanged for size only (not color).
- Exchanges cannot be combined with additional discounts or promotions.
